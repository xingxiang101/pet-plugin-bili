# 定时浏览结果的产品内分享

插件 0.1.1 包含定时浏览结果的产品内分享：宠物定时自主浏览的最终结果显示为宠物气泡，留在聊天窗口并进入驿站。此能力需要宿主提供 `pet.ai.share`。

成功的 night 任务调用宿主实验能力 `pet.ai.share(finalTaskId)`；正文只使用最终已完成结果，不重新调用模型。提示词要求以当前宠物口吻分享真实发现和实际读取过的视频链接。产品内分享不依赖 B 站评论/私信的 share.enabled，也不构成站外发送授权。

宿主保存一条宠物聊天消息和关联驿站未读入口，点击定位原消息；宠物空闲时显示气泡。正在聊天或聊天窗展开时，不覆盖前台回复。重复调用不重复消息、通知或气泡，不重置已读；重启不重放旧任务。skip、失败、取消不分享。手动观看继续使用原 ai.deliver。

旧宿主缺少 ai.share 时，任务记录 delivery=unavailable，面板明确显示暂未送达。兼容基线为含 ai.share 的桌宠 Test 构建（本地验证来源在发布记录中列明）；最低已发布兼容宿主版本尚未确定。源码和本地候选不代表市场包已更新，0.1.0 不包含此功能。

验证由 test:controller 覆盖定时 tick/去重、站外开关独立、跳过/取消/失败/旧宿主；test:electron 使用真实 Electron、插件进程与 20 秒调度器，模型/账号/B 站请求使用明确的本地夹具，验证聊天、驿站和重启。它不证明线上视频理解质量或站外发送。

# 状态通知（2026-11-01）

用户明确要求 B 站生活的状态通过宠物气泡和驿站呈现，并选择「只提示结果和需要处理的状态」。开始、空轮询和内部阶段保持安静。完成、失败、明确取消、待审、审核结果、重启中断、开启活动却缺少账号连接和连续监听错误应有可回看的通知。

业务状态由插件形成简短真实摘要，经宿主公开 SDK 交付；不得直写宿主数据库。评论任务结束不代表评论发送成功，未经实际发送/回读确认不得这样描述。通知不含凭据、原始日志、草稿正文或私人日记；重复故障合并，同一事件不重复通知。

当前源码需要支持实验性 pet.notify 的宿主才能完整持久化状态到驿站。旧宿主降级气泡并明确记录 bubble-only；不能声称已进入驿站。成功观看和定时浏览复用 ai.share，持久化完整结果及同一条驿站引用。此源码变更尚未发布插件版本。

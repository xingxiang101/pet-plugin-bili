# 浏览结果的产品内分享

0.3.0 通过通用 `pet.pet.notify({id, text, scope})` 交付手动观看和定时浏览的最终结果：宠物气泡、聊天记录及关联驿站入口使用同一条消息。该接口不依赖完成的 AI 任务 ID；插件把已有真实最终正文交给宿主，不另调模型。历史已发布版本的实现和兼容基线见各自发布记录。

正文最多 128000 字符。稳定消息 ID 为 task:<插件任务 ID>:result，scope 在任务所属宠物环境建立时捕获。发送失败保存完整正文，后续重试和重启只补发该消息，不重做 AI 或 B 站操作。取消任务通过 `pet.pet.notify({id, scope, cancel: true})` 撤销尚未提交的消息；已保存的内容不撤回。切换身份、停用及卸载继续拒绝迟到结果。

宿主保存一条宠物聊天消息和关联驿站未读入口，点击定位原消息；空闲时显示气泡。正在聊天或聊天窗展开时不覆盖前台回复。重复通知不重置已读、不重弹气泡。只分享实际完成结果；skip 和日常空轮询保持安静。失败、取消、待审及需要处理的状态使用同一接口发送简短说明，不转发原始错误或私密草稿。

产品内分享不依赖 B 站评论/私信的 share.enabled，也不构成站外发送授权。提示词继续要求当前宠物口吻、真实发现和实际读取过的视频链接。

能力检查与业务回退不再调用 ai.share / ai.deliver。缺少 pet.notify 的旧宿主拒绝启动要求回到聊天的观看流程；已有后台任务结果保留在面板，简短临时气泡仅提示未完整送达。需要含本次通用接口契约的配套桌宠测试构建；源码、版本号及本地候选不代表市场或已安装客户端已更新。

验证沿用 test:controller 与 test:electron，覆盖完整正文、重试、取消、定时调度、权限/身份隔离和三个消息落点。真实 Electron 和插件进程使用隔离环境；模型、账号与 B 站请求使用本地夹具，不证明真实站外发送或线上模型质量。
